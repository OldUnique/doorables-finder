1. NO-REFRESH DELETE
========================

Replace your delete button code with:

onClick={async () => {
  const { error } = await supabase
    .from("marketplace_listings")
    .delete()
    .eq("id", item.id);

  if (error) {
    alert("Delete failed: " + error.message);
    return;
  }

  setListings((prev) => prev.filter((listing) => listing.id !== item.id));
}}
